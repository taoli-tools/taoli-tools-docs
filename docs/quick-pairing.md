# 快捷配对

在 [交易页面](./trading-page-guide/) 的「添加交易对区域」，最左边的输入框（占位文字是 `Symbol, CA`）除了当作普通的币种搜索框以外，还可以直接输入一条**配对表达式**，一次性把 A、B 两边都自动选好，省去在两个下拉框里翻找的过程。

例如输入：

```
BG-P:SIREN/USDT+OD-S:SIREN/USDT
```

A 会自动选中 Bitget 的 SIREN/USDT 永续合约，B 会自动选中 OKX DEX 的 SIREN/USDT 链上现货，接着填好 Size 等参数点 Add Pair 即可。

## 语法

```
<交易所短码>-<类型码>:<BASE>/<QUOTE> + <交易所短码>-<类型码>:<BASE>/<QUOTE>
└────────────  A 边  ────────────┘   └────────────  B 边  ────────────┘
```

拿开头的例子拆开看：

| 片段     | 含义                            |
| -------- | ------------------------------- |
| `BG`     | 交易所短码，Bitget              |
| `-`      | 固定分隔符                      |
| `P`      | 类型码，Perp 永续合约           |
| `:`      | 固定分隔符                      |
| `SIREN`  | BASE，基础币种                  |
| `/`      | 固定分隔符                      |
| `USDT`   | QUOTE，计价币种                 |
| `+`      | 分隔 A、B 两边                  |
| `OD-S:…` | B 边，OKX DEX 的现货 SIREN/USDT |

**加号前面是 A，后面是 B**，顺序不能颠倒。

## 书写细则

- 必须**恰好两段**，中间用**一个** `+` 连接。只写一边，或者写三段，都不会生效。
- 交易所短码是**恰好 2 个字母**，类型码是**恰好 1 个字母**，都不区分大小写，`bg-p` 和 `BG-P` 等价。
- `-`、`:`、`/` 三个分隔符一个都不能少，而且它们的前后不能有空格。
- 只有整条表达式的最前面、最后面，以及 `+` 的两侧允许有空格，其它位置出现空格表达式就失效。
  - 有效：`BG-P:SIREN/USDT + OD-S:SIREN/USDT`
  - 无效：`BG-P: SIREN/USDT+OD-S:SIREN/USDT`
- BASE 和 QUOTE 里不能出现空格、`/` 和 `+`，其它字符（数字、`:`、下划线等）都可以，比如 `1000CHEEMS`、`kPEPE`。
  - 币种符号里带 `+` 的交易对没法用表达式书写，因为 `+` 被用来分隔 A、B 两边了，这种情况请用下拉框手动选。
- BASE 和 QUOTE 是**精确匹配**（只是不区分大小写），不是搜索框那种模糊匹配，必须和工具里显示的符号完全一致。例如写 `SIREN/USDT` 不会匹配到 `1000SIREN/USDT`。

> [!TIP]
> 表达式只要有任何一处不符合规则，整条就当作没写，输入框会退回成普通的 Symbol / CA 搜索框，两个下拉框也会按普通搜索的结果来显示。所以「输入之后 A、B 没有自动填上」通常意味着表达式写错了，或者没有匹配到任何交易对。

## 类型码

| 类型码 | 含义              |
| ------ | ----------------- |
| `S`    | Spot 现货         |
| `C`    | Cross 全仓杠杆    |
| `I`    | Isolated 逐仓杠杆 |
| `P`    | Perp 永续合约     |

类型码必须是该交易所真的支持的类型，否则匹配不到任何交易对。比如链上 DEX 只有现货，`OD-P:…` 是写不出结果的。

## 自动填充的行为

表达式解析成功之后：

- A、B 两个下拉框的候选会被收窄成表达式匹配到的交易对，方便核对和手动改。
- 每一边会自动选中：在 Settings 里配置好、并且认证成功的账户中，**按账户名称升序排在最前面**的那个匹配账户下的交易对。
- 只匹配上一边时会保留自动填充状态，等另一个交易所的交易对列表加载回来后再补上；两边都填好后才停止。
- 手动改动 A 或 B 之后，自动填充就关闭了，不会再被表达式覆盖。
- 点击 Add Pair 之后表达式会留在输入框里并重新匹配一次，方便照着同一条表达式连续添加多组。重新输入或者再次粘贴同样的文本，也会重新触发匹配。

## 注意事项

- **必须先添加交易所账户**。表达式只在已配置且认证成功的账户里找交易对，没配置 Bitget 就写不出 `BG-P:…` 的结果。
- **同一个交易所有多个账户时**，自动填充只会选中账户名排序最靠前的那个。想用同一交易所的两个不同账户对冲，表达式区分不了，需要在下拉框里手动改。
- **链上 DEX 的代币要本地已有**。表达式生效时不会再按输入内容去联网搜索合约地址，只能匹配已经保存在本地代币列表里的代币。第一次交易某个链上代币时，请先用普通搜索方式输入合约地址把它加进来，之后再用表达式。
- **DEX 多链同名代币会有多个候选**。表达式里没有指定链的位置，同一个符号在多条链上都存在时，自动选中的不一定是你想要的那条链，请在下拉框里确认。
- **表达式不看交易对状态**。已下架（`!`）或处于非正常状态（`?`）的交易对同样会被匹配到，仍需自己留意下拉框里的提示。

## 示例

| 表达式                            | 含义                                                   |
| --------------------------------- | ------------------------------------------------------ |
| `BN-S:BTC/USDT+BN-P:BTC/USDT`     | Binance 现货 对 Binance 永续                           |
| `BG-P:SIREN/USDT+OD-S:SIREN/USDT` | Bitget 永续 对 OKX DEX 链上现货                        |
| `OK-C:ETH/USDT+HL-P:ETH/USDC`     | OKX 全仓杠杆 对 Hyperliquid 永续，两边计价币种可以不同 |
| `GT-I:DOGE/USDT+MX-P:DOGE/USDT`   | Gate 逐仓杠杆 对 MEXC 永续                             |
